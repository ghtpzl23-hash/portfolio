Reflecting Values through Clarity

  • Clarity : 군더더기 없는 명확한 소통
  • Value : 본질에 집중하는 디자인 가치
  • Trust : 정직한 프로세스로 쌓는 신뢰
"저는 복잡함을 걷어낸 명확한 디자인(Clarity)이
브랜드가 가진 본연의 가치(Values)를 가장 잘 비춘다고 믿습니다.
유리구슬처럼 투명하고 정직한 시각 언어로
사용자에게 신뢰를 주는 디자이너가 되겠습니다."
